# FoundIt Demo Video Script (3–5 minutes)

Record the deployed app in a browser. Before recording, prepare two accounts and a test FOUND listing. Use fictional data only. Do not show secrets, `.env` files, or private database settings.

## 0:00–0:25 — Problem and product

“FoundIt is a campus lost-and-found platform. Lost belongings are often reported across scattered group chats. FoundIt gives the campus one searchable place to report items, submit claims, and close the loop when an item is returned.” Show the homepage and public listings.

## 0:25–1:00 — Discovery

Search for an item by name or location. Switch between All, Lost and Found, change category, and show item cards and details. Explain that search and filters query the backend rather than relying on a hardcoded frontend list.

## 1:00–1:40 — Authentication and listing creation

Register or log in as the owner. Open Report Item, create a FOUND listing with a realistic title, description, category, location and date, and publish it. Show that it appears in the listing feed and My Listings.

## 1:40–2:35 — Claim workflow

Open a second browser profile or private window and log in as another test account. Open the found listing and submit a claim with identifying details that are not sensitive. Return to the owner account and show the pending claim. Approve it and explain that ownership checks and state-transition rules are enforced on the backend.

## 2:35–3:05 — Close the loop

Mark the item as returned. Show that it is no longer in the public discovery feed but is still visible to the owner in My Listings.

## 3:05–3:40 — Engineering and wrap-up

Briefly show the project structure and mention React, Express, MongoDB/Mongoose, JWT authentication, bcrypt password hashing, validation, protected routes, and API error handling. Finish with the product's value: one central place to help campus belongings find their way home.

## Recording checklist

- Verify all steps work before recording.
- Use a screen recorder and narrate naturally; avoid reading every line verbatim.
- Keep the final recording between 3 and 5 minutes if possible.
- Upload the video with permissions that let the evaluator watch it.
